# Research notes: format

Every note answers one question for Maple Street Bakery, an invented small business (sample data). Use this shape:

1. **Answer.** One paragraph that answers the question directly.
2. **Comparison table.** One row per option; every claim cites a source by number, like `[1]`.
3. **Recommendation.** Two or three sentences: which option, and why.
4. **Sources.** A numbered list of public web pages, each with the date it was read.

Keep notes short (a page or two). Don't guess: if a fact can't be found, say so in the table.

See `example-note.md` for the layout.
